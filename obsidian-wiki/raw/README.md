# 📦 raw/ — 불변 원본 보관소

## 이 폴더의 성격
**한 번 들어오면 절대 바뀌지 않는 원본 자료**만 둡니다.
냉장고 속 **손질 안 한 재료**라고 생각하세요.

## 넣는 것
- 회의록 원문 → `meetings/`
- 계약서·견적서·기획서 등 문서 → `documents/`
- 기사·경쟁사 영상 대본·외부 자료 → `sources/`

## 절대 금지
- ❌ 파일 **수정** 금지
- ❌ 파일 **삭제** 금지
- ❌ 요약해서 저장 금지 (원문 그대로)

정정이 필요하면 **새 파일을 추가**하고 `source:` 로 옛 파일을 가리키세요.

## 파일명
`YYYY-MM-DD_출처_제목.md`
예) `2026-09-05_카카오톡_추석행사-견적문의.md`

## 넣는 방법
에이전트에게 **"이 자료 원본으로 넣어줘"** (= `ingest`) 라고 말하세요.
