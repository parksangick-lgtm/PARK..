# AGENTS.md — 모든 AI 에이전트 공통 진입점

> Claude Code, Cursor, Codex 등 **어떤 AI 에이전트가 들어와도 동일하게 동작**하도록 하는 요약 규칙입니다.
> **정본은 [CLAUDE.md](CLAUDE.md) 입니다.** 충돌하면 CLAUDE.md 를 따르세요.

## 0. 처음 들어온 에이전트가 할 일 (순서대로)

1. `CLAUDE.md` 를 끝까지 읽는다. ← **생략 금지**
2. `index.md` 로 위키 지도를 파악한다.
3. `log.md` 최근 10줄로 진행 상황을 파악한다.
4. 작업을 시작한다.

## 1. 3개 영역 (외우고 시작할 것)

- `raw/` = **불변 원본**. 절대 수정·삭제 금지.
- `conversations/` = **대화 로그**. 추가만 가능.
- `wiki/` = **검증된 지식**. 5-필터를 통과한 것만 들어간다.

## 2. 명령어 (영어 고정) — 트리거 전체 목록

영어 명령어를 그대로 입력해도 되고, 아래 한국어 문장 중 **아무거나** 써도 같게 동작한다.

| 명령어 | 한국어 트리거 (모두 인식) | 읽기 | 쓰기 |
|---|---|---|---|
| `save` | **이번 작업 내용 옵시디언에 저장해줘** / 옵시디언 저장 / 위키에 저장해줘 / 기록해줘 | index, 관련 wiki, 현재 대화 | conversations(항상) + wiki(필터 통과분) + log + index |
| `reference` | **옵시디언 참조** / 위키 참조해줘 / 맥락 불러와줘 / 지난 내용 알려줘 | index → log → 관련 wiki | **없음 (읽기 전용)** |
| `ingest` | 이 자료 원본으로 넣어줘 / 옵시디언에 원본 저장 / raw에 넣어줘 | 사용자가 준 원본 | raw/ (원문 그대로) + log |
| `query` | 위키에서 찾아줘 / 옵시디언에서 검색 / 전에 뭐라고 정했지? | wiki → raw → conversations | **없음** — 답변에 `[출처: 경로]` 필수 |
| `lint` | 옵시디언 점검해줘 / 위키 정리해줘 / 린트 돌려줘 | wiki 전체 | **없음 (보고만)** |

**모든 명령은 실행 후 `log.md` 에 한 줄을 남긴다.** (`날짜 | 명령 | 내용 | 승격 | 관련 파일`)

### 인식 규칙
- 문장이 정확히 일치하지 않아도 **핵심어 조합**으로 판단한다.
  (`옵시디언|위키` + `저장` → save / `옵시디언|위키` + `참조|맥락` → reference)
- **모호하면 실행하지 말고 되묻는다.**
- 실행 전에 **어떤 명령으로 이해했는지 한 줄로 밝힌다.**

## 3. wiki 승격 5-필터 (하나라도 통과해야 함)

1. 반복 재사용될 데이터인가?
2. 인수인계에 반드시 필요한가?
3. 의사결정 근거·결정권자 추적이 필요한가?
4. 다시 시도하면 안 되는 실패·리스크 정보인가?
5. 팀 공통 규칙·디자인 가이드인가?

→ **하나도 아니면 `wiki/` 승격 금지.** `conversations/` 나 `raw/` 에만 남긴다.

통과시켰다면 노트에 **두 가지를 모두** 적는다. 하나라도 빠지면 `lint` 가 잡는다.
- `filters: [1, 5]` — 어떤 필터를 통과했나
- `filter_reason: …` — **왜** 통과했나 (한 줄)

### 승격 금지 (필터 볼 것도 없음)
일회성 답변 · 사소한 중간 생각 · 검증 안 된 추측 · 외부 원문 그대로 · 대화 복붙

### Raw 불변성 보증
`raw/` 의 모든 파일은 `raw/.manifest` 에 지문(SHA256)이 등록되어 있다.
`ingest` 직후 `bash tools/raw-guard.sh seal` 을 실행하고,
`lint` 는 `verify` 로 훼손 여부를 자동 검사한다.

## 4. 4가지 금지사항

1. `raw/` 수정 금지
2. 대화 내용 `wiki/` 로 그대로 복사 금지 (재작성 필수)
3. 검증 안 된 추측 `wiki/` 저장 금지 (`> 추정입니다` 붙여 conversations 로)
4. 출처(`source`) 없는 결정 `wiki/` 저장 금지
5. 새 자료가 기존 노트와 충돌하면 **조용히 덮어쓰지 말고** 모순 블록으로 기록 후 사람 판정 대기

## 5. 세션 종료 시 (중요)

사용자가 명령하지 않아도 **대화가 끝날 때 `save` 를 자동 실행**하고, 승격 목록을 표로 보고한다.
사용자가 "그건 빼줘"라고 하면 즉시 `conversations/` 로 강등한다.
