# AGENTS.md — 모든 AI 에이전트 공통 진입점

> Claude Code, Cursor, Codex 등 **어떤 AI 에이전트가 들어와도 동일하게 동작**하도록 하는 요약 규칙입니다.
> **정본은 [CLAUDE.md](CLAUDE.md) 입니다.** 충돌하면 CLAUDE.md 를 따르세요.

## 0. 처음 들어온 에이전트가 할 일 (순서대로)

1. `CLAUDE.md` 를 끝까지 읽는다. ← **생략 금지**
2. `index.md` 로 위키 지도를 파악한다.
3. `log.md` 최근 10줄로 진행 상황을 파악한다.
4. 작업을 시작한다.

## 1. 3개 영역 (외우고 시작할 것)

- `raw/` = **불변 원본**. 절대 수정·삭제 금지.
- `conversations/` = **대화 로그**. 추가만 가능.
- `wiki/` = **검증된 지식**. 5-필터를 통과한 것만 들어간다.

## 2. 명령어 (영어 고정)

| 명령어 | 한국어 트리거 | 읽기 | 쓰기 |
|---|---|---|---|
| `save` | 이번 작업 내용 옵시디언에 저장해줘 | index, wiki | conversations + (필터 통과 시) wiki + log + index |
| `reference` | 옵시디언 참조 | index → log → wiki | **없음** |
| `ingest` | 이 자료 원본으로 넣어줘 | 사용자 원본 | raw |
| `query` | 위키에서 찾아줘 | wiki → raw → conversations | **없음** |
| `lint` | 옵시디언 점검해줘 | wiki 전체 | **없음 (보고만)** |

## 3. wiki 승격 5-필터 (하나라도 통과해야 함)

1. 반복 재사용될 데이터인가?
2. 인수인계에 반드시 필요한가?
3. 의사결정 근거·결정권자 추적이 필요한가?
4. 다시 시도하면 안 되는 실패·리스크 정보인가?
5. 팀 공통 규칙·디자인 가이드인가?

→ **하나도 아니면 `wiki/` 승격 금지.** `conversations/` 나 `raw/` 에만 남긴다.

## 4. 4가지 금지사항

1. `raw/` 수정 금지
2. 대화 내용 `wiki/` 로 그대로 복사 금지 (재작성 필수)
3. 검증 안 된 추측 `wiki/` 저장 금지 (`> 추정입니다` 붙여 conversations 로)
4. 출처(`source`) 없는 결정 `wiki/` 저장 금지
