# 홈페이지 개발 현황

**회사 홈페이지를 직접 제작**한다.

## 현재 보유 자산 (이 저장소)

| 항목 | 내용 |
|---|---|
| 저장소 | `parksangick-lgtm/PARK..` |
| 기존 기능 | 유튜브 자막 자동 요약 (`src/summarize.py`) |
| 실행 방식 | 개인 PC (`실행하기.bat` / `실행하기.command`) |
| 제약 | GitHub Actions 등 클라우드 IP는 유튜브가 차단 → **자동 실행 불가, 개인 PC 실행 필수** |
