# 사업 현황

> **에이전트에게**: 이 노트는 "박상익이 무슨 일을 하는 사람인가"를 파악하는 **첫 관문**입니다.
> 빈칸은 **확인되지 않은 것**입니다. 채워지기 전까지 추측으로 메우지 마세요.

## 4개 축

| 영역 | 내용 | 상태 |
|---|---|---|
| **박상익출장음식** | 출장 케이터링 | 세부사항 미확인 |
| **유튜브 - 별빛마실** | 시니어 가족드라마 쇼츠 | [[wiki/20-유튜브/별빛마실-채널-가이드\|가이드 있음]] |
| **유튜브 - 노을빛 정거장 / 심리채널** | 추가 채널 | 미확인 |
| **BNI** | 비즈니스 네트워킹 활동 | 미확인 |
| **회사 홈페이지** | 바이브 코딩으로 직접 제작 학습 중 | [[wiki/40-홈페이지개발/개발-현황\|진행중]] |

## ⚠️ 확인이 필요한 항목
- [ ] 출장음식 — 주요 메뉴·단가·1회 평균 수주 규모·수주 경로
- [ ] 출장음식 — 성수기/비수기
- [ ] BNI — 소속 챕터, 맡은 역할, 주간 미팅 요일
- [ ] 유튜브 3개 채널의 역할 분담
- [ ] 세 사업의 시간 배분 우선순위

**채우는 방법**: 관련 자료를 주시고 **"이 자료 원본으로 넣어줘"** → 그 다음 **"이번 작업 내용 옵시디언에 저장해줘"**
