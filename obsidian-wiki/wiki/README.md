# 📗 wiki/ — 검증된 지식 창고

## 이 폴더의 성격
`raw/` 의 원본을 바탕으로 **정리된 실행 규칙·의사결정·재사용 지식**만 둡니다.
**바로 꺼내 먹을 수 있는 완성된 반찬**입니다.

## 들어오려면 — 5-필터 중 최소 1개 통과 필수
1. 반복 재사용될 데이터인가?
2. 인수인계에 반드시 필요한가?
3. 의사결정 근거·결정권자 추적이 필요한가?
4. 다시 시도하면 안 되는 실패·리스크 정보인가?
5. 팀 공통 규칙·디자인 가이드인가?

**하나도 아니면 여기 못 들어옵니다.** → `conversations/` 로 보내세요.

## 여기 두면 안 되는 것
- ❌ 검증 안 된 추측 ("아마 ~일 것이다")
- ❌ 출처(`source`) 없는 결정
- ❌ 일회성 답변, 사소한 중간 생각
- ❌ 대화 내용 복붙 (반드시 재작성)

## 폴더 번호 체계
| 번호 | 영역 |
|---|---|
| `00-회사개요` | 사업 전체 현황 |

| `20-유튜브` | 별빛마실 외 채널 |
