# 별빛마실 채널 가이드

## 한 줄 요약
60~70대 주인공의 가족 드라마 사연을 **세로 쇼츠 2분 30초 내외**로 제작하는 시니어 채널.

## 채널 정체성 (확정)

| 항목 | 내용 |
|---|---|
| 채널명 | 별빛마실 |
| 타깃 | 시니어 시청자 |
| 주인공 연령대 | **60~70대** |
| 소재 | 가족 갈등 · 화해 · 재산 · 간병 |
| 영상 형식 | **세로 영상 쇼츠** |
| 러닝타임 | **약 2분 30초 내외** |

## 소재 4대 축
1. **가족 갈등** — 자녀·며느리·사위와의 마찰
2. **화해** — 오해가 풀리는 전환점
3. **재산** — 유산·상속·명의 문제
4. **간병** — 부모 돌봄, 배우자 간병

## 대본 기준
- 러닝타임 2분 30초를 넘기지 않는다. (넘으면 이탈률 상승)
- 주인공은 반드시 60~70대 1인칭 시점.
- 초반 5초 안에 **갈등 상황**을 제시한다.
- 마지막은 화해 또는 여운으로 닫는다.
