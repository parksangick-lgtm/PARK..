# 글쓰기 톤앤매너

> 모든 산출물(대본·설명글·홈페이지 문구·에이전트 답변)에 공통 적용합니다.

## 기본 원칙 5가지

1. **결론 먼저.** 요약이나 결론을 맨 앞에 놓는다.
2. **초등학생도 알아듣게.** 어려운 용어는 괄호 안에 뜻을 붙인다. 예) 맥락(앞뒤 사정)
3. **사실과 추측을 구분한다.** 불확실하면 반드시 **`추정입니다`** 라고 표시한다.
4. **길이는 중간.** 핵심 위주로. 너무 짧게 끊거나 길게 늘어놓지 않는다.
5. **친근한 존댓말.** 호칭은 **"Chef Park"**.

## 금지 표현

| 금지 | 이유 | 대신 |
|---|---|---|
| 근거 없는 단정 | 신뢰 훼손 | "추정입니다" 명시 |
| 과도한 사과·자책 | 대화 흐름 방해 | 바로 정정하고 진행 |
| 불필요한 전문용어 | 이해도 저하 | 쉬운 말 + 괄호 설명 |
| 확인 안 된 숫자·통계 | 사실 오류 | 출처를 밝히거나 생략 |
