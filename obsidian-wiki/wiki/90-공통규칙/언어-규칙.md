# 한글·영문 혼용 규칙

## 왜 섞어 쓰나
- **사람(Chef Park)** 은 한국어로 읽어야 빠르고 정확하게 판단합니다.
- **에이전트**는 영어 키워드가 흔들리지 않아야 매 세션 **똑같이** 동작합니다.

두 목적이 다르므로 **역할별로 언어를 나눕니다.**

## 한국어로 쓰는 것 (사람이 읽고 편집)

| 대상 | 예시 |
|---|---|
| 톤앤매너 | "결론 먼저, 쉬운 말, 친근한 존댓말" |
| 금지 표현 | "근거 없는 단정 금지" |
| 업무 지침 | 행사 당일 순서, 수주 절차 |
| 기획 기준 | 쇼츠 러닝타임 2분 30초, 주인공 60~70대 |
| 설명문·주석 | 노트 본문 전체 |
| 노트 파일명 | `별빛마실-채널-가이드.md` |

## 영어로 고정하는 것 (에이전트가 인식)

| 대상 | 값 | 바꾸면 안 되는 이유 |
|---|---|---|
| 명령어 | `save` `reference` `ingest` `query` `lint` | 번역하면 세션마다 다르게 해석됨 |
| frontmatter 키 | `type` `title` `area` `status` `owner` `source` `created` `updated` `filters` `tags` | 자동 점검(`lint`)이 키 이름으로 파일을 읽음 |
| 폴더명 | `raw` `wiki` `conversations` `templates` `tools` | 경로가 규칙 문서에 하드코딩되어 있음 |
| 상태값 표기 | `확정` `검토중` `폐기` (값은 한국어, 키는 영어) | 사람이 판단하는 값이므로 한국어 유지 |

## 지켜야 할 한 줄 원칙

> **"읽는 건 한국어, 실행하는 건 영어."**

## 헷갈릴 때
- 이 문장을 **사람이 고칠 일이 있나?** → 한국어
- 이 단어를 **에이전트가 찾아서 판단하나?** → 영어 고정
