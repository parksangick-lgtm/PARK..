# 💬 conversations/ — 대화 로그 보관소

## 이 폴더의 성격
AI 와 나눈 **대화 원문과 중간 사고 과정**을 남기는 곳입니다.
**요리하다 나온 자투리**를 모아두는 곳이라고 보시면 됩니다. 버리진 않되, 손님상에는 안 올립니다.

## 여기에 남기는 것
- 5-필터를 **통과하지 못한** 모든 내용
- 일회성 답변, 사소한 중간 생각
- 검증되지 않은 추측 (반드시 `> 추정입니다` 표기)
- 나중에 다시 볼 수도 있는 브레인스토밍

## 규칙
- ✅ 추가만 가능 (append-only)
- ❌ 여기 있는 내용을 **그대로 `wiki/` 로 복사 금지** — 반드시 5-필터를 거쳐 **재작성**
- 승격할 때는 `wiki/` 노트의 `source:` 에 이 파일 경로를 적습니다

## 파일명
`YYYY-MM-DD_주제.md`
예) `2026-09-05_옵시디언-위키-설계.md`
