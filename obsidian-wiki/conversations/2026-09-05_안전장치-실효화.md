# 세션 기록: 안전장치 실효화

## 점검으로 드러난 문제
규칙 문서에는 적혀 있으나 **실제로는 아무것도 막지 못하는** 항목이 4개였다.

| 안전장치 | 점검 전 | 조치 |
|---|---|---|
| Raw 불변성 | ❌ 양심에만 의존 | `tools/raw-guard.sh` 지문(SHA256) 대조 신설 |
| 필터 번호 유효성 | ❌ 없음 | lint 3번 확장 (1~5 외 값 차단) |
| 필터 판정 근거 | ❌ 번호만 있고 이유 없음 | `filter_reason` 필수화, 기존 11건 소급 기재 |
| 대화 복붙 방지 | ❌ 없음 | lint 12번 신설 (동일 문장 3줄 이상 탐지) |

## 실제 작동 검증 (테스트해서 확인)
- Raw 훼손: `raw/README.md` 에 한 줄 추가 → **🚨 내용이 변경됨** 탐지 성공 → 원상복구
- 복붙: 산문 5줄을 그대로 wiki 로 복사 → **동일 문장 5줄** 탐지 성공 → 제거
- 1차 복붙 테스트는 복사한 줄이 표·빈줄이라 기준(3줄) 미달로 미탐지.
  테스트가 부실했던 것이며 검사 자체는 정상이었음. 산문으로 재시험해 확인함.

## 위키 승격 판정
| 항목 | 통과 필터 | 저장 위치 |
|---|---|---|
| Raw/Wiki 경계 정의 + 불변성 보증 절차 | 1,2,5 | CLAUDE.md §2 |
| 5-필터 판정 5단계 절차 + 승격 금지 목록 | 1,5 | CLAUDE.md §4 |

## 승격하지 않은 것
- 테스트에 쓴 임시 파일 내용 → 일회성
- lint 스크립트 디버깅 과정 → 중간 사고 과정
