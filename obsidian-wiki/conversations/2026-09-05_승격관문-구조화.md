# 세션 기록: 승격 관문 구조화

## 발견한 불일치
`CLAUDE.md` §6-3 은 중복 검사 기준을 "제목·**핵심 문장**이 70% 이상 겹침"이라 적어두었으나,
실제 `lint.sh` 는 **제목만** 비교하고 있었다. 규칙과 구현이 어긋난 상태.

## 조치
| 항목 | 내용 |
|---|---|
| `tools/dupcheck.py` 신설 | frontmatter·표·제목줄을 빼고 실제 문장만 비교. 짧은 쪽 기준 70% 이상 겹치면 보고 |
| `tools/promote-check.sh` 신설 | wiki 진입 **전** 3단계 관문. 통과해야만 승격 가능 |
| `save` 절차 4단계로 관문 삽입 | 🔴 차단을 무시하고 옮기지 않도록 명문화 |

## 관문 3단계
1. 승격 금지 목록 — 검증 안 된 추측 / 대화 원문 복붙
2. 5-필터 판정 — `filters` 유효성(1~5), `filter_reason` 기재
3. 출처 — `source` 존재 및 경로 유효성

## 실제 작동 검증
| 시험 | 결과 |
|---|---|
| 정상 노트 (언어-규칙.md) | 🟢 승격 가능 |
| 일회성 답변 (filters 비어있음) | 🔴 차단 |
| 검증 안 된 추측 ("아마도~할 듯") | 🔴 차단 |
| 출처 없는 결정 (없는 경로) | 🔴 차단 |

lint 요구 4항목(추측·중복·무출처·노후)을 한 파일에 심어 시험한 결과 **4건 모두 탐지**.

## 위키 승격 판정
| 항목 | 통과 필터 | 저장 위치 |
|---|---|---|
| 승격 관문 3단계 절차 | 1, 2, 5 | CLAUDE.md §4 |

## 승격하지 않은 것
- 시험용 불량 노트 내용 → 일회성
- dupcheck 임계값을 0.7로 정한 계산 과정 → 중간 사고
