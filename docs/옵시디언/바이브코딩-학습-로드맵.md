# 바이브코딩 학습 로드맵

> [!abstract] 이 노트의 목적
> **"코드를 배우는 것"이 아니라 "AI에게 잘 시켜서 홈페이지를 완성하는 것"** 이 목표입니다.
> 모르는 단어가 나오면 [[바이브코딩-용어사전]] 을 열어보세요.

> [!tip] 체크박스 쓰는 법
> 옵시디언에서 `- [ ]` 앞의 네모를 마우스로 누르면 `✅` 체크로 바뀝니다. 진도 표시에 쓰세요.

---

## 전체 그림 (4단계)

| 단계 | 기간(추정) | 무엇을 하나 | 끝나면 생기는 것 |
|---|---|---|---|
| **1단계** | 1주 | 도구 설치하고 말 걸어보기 | AI와 대화해서 파일 만들기 성공 |
| **2단계** | 1~2주 | 한 장짜리 홈페이지 만들기 | 내 컴퓨터에서 열리는 홈페이지 |
| **3단계** | 1주 | 깃허브에 올리고 인터넷에 공개 | 남에게 보여줄 수 있는 주소 |
| **4단계** | 계속 | 내용 채우고 다듬기 | 실제 회사 홈페이지 완성 |

> 기간은 하루 1~2시간 기준 **추정입니다.** 사람마다 다릅니다.

---

## 1단계 — 도구 준비하고 친해지기

### 설치할 것

- [ ] **VS 코드** 설치 (무료) — 코드를 쓰고 보는 창
- [ ] **깃(Git)** 설치 (무료) — 변경 기록을 남기는 도구
- [ ] **깃허브(GitHub)** 계정 만들기 (무료) — 인터넷 저장 창고
- [ ] **Claude Code** 설치 — AI에게 일을 시키는 도구
- [ ] **옵시디언** 설치 (개인 무료) — 배운 것 정리하는 곳

### 연습할 것

- [ ] VS 코드에서 **터미널** 열어보기 (검은 글자 창)
- [ ] AI에게 "이 폴더에 인사말 파일 하나 만들어줘" 시켜보기
- [ ] 만들어진 파일 열어서 눈으로 확인하기
- [ ] AI에게 "그 파일 내용을 이렇게 바꿔줘" 시켜보기

> [!warning] 이 단계의 핵심
> **아무것도 외우지 마세요.** "AI에게 말하면 파일이 생긴다"는 감만 잡으면 1단계는 성공입니다.

---

## 2단계 — 한 장짜리 홈페이지 만들기

### 만들기 전에 종이에 적을 것

- [ ] 회사 이름과 한 줄 소개
- [ ] 어떤 일을 하는지 (3~4가지)
- [ ] 사진 몇 장 (음식 사진, 행사 사진 등)
- [ ] 연락처 (전화번호, 카톡, 이메일)
- [ ] 원하는 분위기 (예: "깔끔하고 정갈한", "따뜻한 느낌")

### AI에게 시켜볼 것

- [ ] "회사 소개 한 장짜리 홈페이지를 만들어줘" 라고 부탁하기
- [ ] 브라우저에서 열어서 눈으로 확인하기
- [ ] "글씨를 좀 더 크게" / "색을 바꿔줘" 처럼 **한 번에 하나씩** 고치기
- [ ] 휴대폰 화면 크기로도 잘 보이는지 확인 (**반응형**)
- [ ] 사진 넣기

> [!tip] 잘 시키는 요령 3가지
> 1. **한 번에 하나만** 부탁하기 — "색 바꾸고 글씨 키우고 사진 넣어줘" ❌
> 2. **눈에 보이는 대로** 말하기 — "위쪽 파란 줄을 좀 얇게" ⭕
> 3. **에러가 나면 그 글자를 그대로 복사해서** AI에게 붙여넣기

---

## 3단계 — 인터넷에 공개하기

- [ ] 깃허브에 **저장소(Repository)** 만들기
- [ ] AI에게 시켜서 **커밋 → 푸시** 해보기
- [ ] 무료 **배포** 서비스 연결하기 (깃허브 페이지 / 버셀 / 넷리파이 중 하나)
- [ ] 휴대폰으로 주소 열어서 진짜 보이는지 확인
- [ ] (선택) **도메인** 사서 연결하기 — 유료

> [!note] 돈이 드는 부분
> - 배포 서비스: 작은 홈페이지는 **무료 요금제로 충분합니다**
> - 도메인(주소): **연 1~2만 원대**가 많습니다 — **추정입니다.** 판매처마다 다릅니다

---

## 4단계 — 계속 다듬기

- [ ] 메뉴/서비스 소개 페이지 추가
- [ ] 사진 갤러리 추가
- [ ] 문의하기 버튼 (전화 걸기 / 카톡 연결)
- [ ] 네이버·구글 검색에 나오게 다듬기 (**SEO**)
- [ ] 유튜브 채널 링크 연결
- [ ] 고친 내용 매번 커밋해서 기록 남기기

## 막혔을 때 이렇게 하세요

| 상황 | 이렇게 하세요 |
|---|---|
| 빨간 글씨(에러)가 떴다 | **그 글자를 통째로 복사해서** AI에게 붙여넣고 "이거 고쳐줘" |
| AI가 엉뚱한 걸 만들었다 | "아니야, 되돌리고 다시 해줘"라고 말하기 |
| 다 망가진 것 같다 | 깃 기록으로 **예전 상태로 되돌리기** — 그래서 커밋이 중요합니다 |
| 무슨 말인지 모르겠다 | [[바이브코딩-용어사전]] 찾아보기 |
| 그래도 모르겠다 | AI에게 **"초등학생에게 설명하듯 알려줘"** 라고 덧붙이기 |

---

## 마음가짐 3가지

1. **완벽하게 이해하려 하지 마세요.** 작동하면 일단 넘어가도 됩니다.
2. **망가뜨려도 괜찮습니다.** 깃이 있으면 언제든 되돌아갑니다.
3. **작게 자주 저장하세요.** 커밋은 많이 할수록 좋습니다.
