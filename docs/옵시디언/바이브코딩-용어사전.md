# 바이브코딩 용어 사전

> [!tip] 쓰는 법
> 이 파일을 옵시디언 보관함(Vault, 노트를 모아두는 폴더) 안에 그대로 넣으면 바로 열립니다.
> `[[대괄호 두 개]]`로 감싼 말은 옵시디언에서 다른 노트로 연결되는 링크입니다.

---

## 1. 기본 개념

- **바이브 코딩(Vibe Coding)**: 코드를 직접 한 줄씩 쓰지 않고, AI에게 말(자연어)로 부탁해서 프로그램을 만드는 방식.
- **프롬프트(Prompt)**: AI에게 시키는 말, 즉 "지시문".
- **컨텍스트(Context)**: AI가 지금 기억하고 있는 대화·파일의 범위. 넘치면 앞부분을 잊습니다.
- **토큰(Token)**: AI가 글자를 세는 단위. 한글 한 글자가 대략 1~2토큰 (추정입니다, 모델마다 다름).
- **환각(Hallucination)**: AI가 없는 사실을 그럴듯하게 지어내는 현상.
- **이터레이션(Iteration, 반복)**: 만들고 → 확인하고 → 고치는 과정을 여러 번 도는 것.

## 2. 웹사이트(홈페이지) 만들 때 나오는 말

- **프론트엔드(Frontend)**: 방문자 눈에 보이는 화면 부분.
- **백엔드(Backend)**: 눈에 안 보이는 서버 쪽 처리 부분 (예: 문의 폼 저장).
- **HTML**: 화면의 뼈대(글, 사진, 버튼의 구조).
- **CSS**: 화면의 꾸밈(색, 크기, 여백).
- **자바스크립트(JavaScript)**: 화면을 움직이게 하는 언어(버튼 클릭 반응 등).
- **반응형(Responsive)**: 휴대폰·태블릿·PC 화면 크기에 맞춰 자동으로 배치가 바뀌는 것.
- **도메인(Domain)**: 홈페이지 주소 (예: `example.com`).
- **호스팅(Hosting)**: 홈페이지 파일을 인터넷에 올려두는 서비스.
- **배포(Deploy)**: 만든 홈페이지를 실제 인터넷에 올려서 남들이 볼 수 있게 하는 일.
- **SEO(검색엔진 최적화)**: 네이버·구글 검색에 잘 나오게 다듬는 작업.

## 3. 도구 이름

- **에디터(Editor)**: 코드를 쓰는 프로그램 (예: VS Code).
- **터미널(Terminal)/명령줄**: 글자를 쳐서 컴퓨터에 명령하는 검은 창.
- **Claude Code**: 터미널에서 AI에게 시켜 코드를 만들게 하는 도구.
- **MCP**: AI가 외부 프로그램(구글 드라이브, 노션 등)과 연결되게 해주는 규격.
- **API**: 프로그램끼리 정보를 주고받는 약속된 창구.
- **라이브러리(Library)**: 남이 미리 만들어둔 기능 묶음. 가져다 쓰면 편합니다.

## 4. 깃(Git) 관련 - 저장과 되돌리기

- **깃(Git)**: 파일이 바뀐 기록을 남겨주는 도구. 언제든 예전으로 되돌릴 수 있습니다.
- **깃허브(GitHub)**: 깃 기록을 인터넷에 보관하는 창고 사이트.
- **레포지토리(Repository, 저장소)**: 프로젝트 파일 한 묶음.
- **커밋(Commit)**: "여기까지 저장!" 하고 도장 찍는 것.
- **푸시(Push)**: 내 컴퓨터의 저장 기록을 깃허브로 올리기.
- **풀(Pull)**: 깃허브에 있는 최신 내용을 내 컴퓨터로 가져오기.
- **브랜치(Branch, 가지)**: 원본을 건드리지 않고 따로 실험하는 복사본 길.
- **머지(Merge, 합치기)**: 실험한 가지를 원래 줄기에 합치는 것.
- **PR(Pull Request)**: "이 변경을 합쳐도 될까요?" 하고 올리는 요청서.
- **충돌(Conflict)**: 같은 줄을 두 사람이 다르게 고쳐 합칠 수 없는 상태.

## 5. 자주 보는 오류·상황 말

- **버그(Bug)**: 프로그램이 잘못 동작하는 문제.
- **디버깅(Debugging)**: 버그를 찾아 고치는 일.
- **에러 로그(Error Log)**: 무엇이 잘못됐는지 컴퓨터가 남긴 기록. 그대로 복사해 AI에게 주면 해결이 빨라집니다.
- **의존성(Dependency)**: 내 프로그램이 돌아가려면 꼭 필요한 다른 프로그램들.
- **설치(Install)**: 그 필요한 것들을 컴퓨터에 넣는 일.
- **로컬(Local)**: 내 컴퓨터 안. **서버(Server)**: 인터넷 저쪽의 컴퓨터.

## 옵시디언에서 더 잘 쓰는 법

1. 이 파일을 보관함에 넣습니다.
2. 용어 하나가 커지면 `[[커밋]]`처럼 링크로 만들어 따로 노트를 팝니다.
3. 왼쪽 아래 **그래프 뷰(Graph View)**를 누르면 용어들이 거미줄처럼 연결된 그림이 보입니다.
4. 태그 `#바이브코딩`으로 검색하면 관련 노트만 모아 볼 수 있습니다.
